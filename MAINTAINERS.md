# NAMROS Maintainers

NAMROS currently uses a maintainer-led governance model.

## Current Maintainer

| GitHub | Scope |
| --- | --- |
| [@nosway](https://github.com/nosway) | Repository administration, releases, security coordination, source-boundary review, and final merge decisions |

## Responsibilities

Maintainers are expected to:

- Review issues and pull requests in a timely and respectful manner.
- Protect S3 compatibility, metadata correctness, and the public source
  boundary.
- Require evidence proportionate to the operational or data-safety risk of a
  change.
- Publish release notes, checksums, SBOMs, provenance, compatibility notes, and
  known limitations.
- Coordinate security reports under [SECURITY.md](SECURITY.md).
- Keep documentation honest about Community behavior, Enterprise development,
  and specification-stage roadmap items.

## Adding Or Removing Maintainers

An existing maintainer may nominate a contributor who has demonstrated
sustained technical work, review quality, and responsible community conduct.
The nomination is recorded in a public issue or pull request unless privacy or
security concerns require a private discussion. Changes to this file and
`CODEOWNERS` are reviewed together.

When a maintainer steps down, repository access should be removed promptly and
the remaining maintainer should publish the resulting ownership and release
continuity plan.
